Q4 in your file is wrong.

> A compiler differs from an interpreter in that a compiler ________.

That's backwards. Correct answer is:
**translates a high-level program into a separate machine language program**

* Compiler = translates whole program at once → creates .exe, then runs. e.g. C, C++, COBOL
* Interpreter = translates and executes one line at a time, no separate file. e.g. Python, BASIC, JavaScript

If UCC asks this, pick the "separate machine language program" option.

### Section A — what to memorize

All 20 are definition-style. The traps are:

1. Program = set of instructions, not a device
2. Runs programs = CPU, not RAM
3. RAM volatile = erased when off
5. Extends ASCII = Unicode
6. Pseudocode = fake code, no strict rules
7. IPO = Input, Process, Output
8. Hand tracing = track variable values line by line
9. camelCase = first word lowercase + Next Words Upper. e.g. `studentName`
10. Comments = internal documentation
11. Breaking large program = Divide and conquer
12. Local variable = only inside that module
13. Hierarchy chart = relationship between modules, no details
14. Parameter = variable that receives argument. Argument = actual value passed
15. Decision symbol = Diamond. Rectangle=process, Oval=start/end, Parallelogram=input/output
16. Range 10-20 inclusive = `x >= 10 AND x <= 20`. `OR` is wrong — with OR, every number passes.
17. Boolean = true/false only
18. Pass by value = only a copy, original unchanged. Pass by reference = original can change
19. Module = group of statements that does one task
20. Display output = `Display`

### Section B — model answers you must be able to write

**1a(i) Area of circle, pass by value [7 marks]:**
```
Module main()
  Declare Real radius
  Display "Enter radius"
  Input radius
  Call calculateArea(radius)
End Module

Module calculateArea(Real r)
  Declare Real area
  Set area = 3.14159 * r * r
  Display "Area is ", area
End Module
```
Key point to write: `radius` is passed by value, so `calculateArea` gets a copy.

**1a(ii) Celsius to Fahrenheit [5 marks]:**
```
Module main()
  Declare Real celsius
  Display "Enter temperature in Celsius"
  Input celsius
  Call convertToFahrenheit(celsius)
End Module

Module convertToFahrenheit(Real c)
  Declare Real f
  Set f = c * 9/5 + 32
  Display "Fahrenheit is ", f
End Module
```

**1b. RAM vs ROM [3 marks]:**
RAM = volatile, temporary, read/write, holds running programs, erased on power off.
ROM = non-volatile, permanent, read-only, holds boot instructions, stays on power off.
Need both: ROM to start computer, RAM to work fast while on.

**1c. Program Development Cycle [5 marks]:**
1. Analyze - understand problem/requirements
2. Design - pseudocode, flowchart, IPO/hierarchy
3. Code - write in language
4. Test & Debug - find and fix errors
5. Implement/Maintain - install, update

**2a. Student average [7 marks]:**
```
Module main()
  Declare String name
  Declare Real m1, m2, m3, avg
  Display "Enter name"
  Input name
  Display "Enter 3 marks"
  Input m1, m2, m3
  Set avg = (m1 + m2 + m3) / 3
  Display name, " average is ", avg
End Module
```

**2b. Variable scope [3 marks]:**
Scope = where variable can be accessed. Local = only inside its module. Same name in two modules = no problem, they are separate — nothing goes wrong. That's the advantage.

**3c. Compiler vs Interpreter — already covered above, add examples.**

**3d. Debugging [5 marks]:**
Debugging = finding and fixing errors.
1. Syntax error - breaks grammar rules, caught by compiler. e.g. missing semicolon
2. Logic error - wrong result, no crash. Found by hand tracing/testing. e.g. using + instead of *
3. Runtime error - crashes during run. e.g. divide by zero. Found by testing.
